┃ ⚡ 5-MINUTE QUICK START                                                  ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

1️⃣  Install Dependencies
   $ cd backend
   $ pip install openai python-dotenv

2️⃣  Configure Environment
   $ cp .env.example .env
   # Edit .env and add OpenAI API key

3️⃣  Setup Database
   $ python manage.py makemigrations
   $ python manage.py migrate

4️⃣  Start Backend
   $ python manage.py runserver
   → http://localhost:8000

5️⃣  Start Frontend (new terminal)
   $ cd frontend && npm start
   → http://localhost:3000

✅ Done! Your chatbot is ready.

POST   /api/chatbot/sessions/                    → Create session
GET    /api/chatbot/sessions/{id}/               → Get session details
POST   /api/chatbot/sessions/{id}/send_message/  → Send & get response
GET    /api/chatbot/sessions/{id}/messages/      → Get all messages
DELETE /api/chatbot/sessions/{id}/clear_session/ → Clear chat
POST   /api/chatbot/sessions/{id}/mark_helpful/  → Rate message

All endpoints require: Authorization: Bearer {JWT_TOKEN}
